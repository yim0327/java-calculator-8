# java-calculator-precourse

# 📝 기능 목록 정리


### 입력
- [x] 사용자는 문자열을 입력할 수 있다.


### 출력
- [x] 프로그램 시작 시 문자열 입력 안내 메시지를 출력한다. (ex. `"덧셈할 문자열을 입력해 주세요.\n"`)

- [ ] 계산 결과에 따른 결과값을 형식에 맞춰 출력한다. (ex. `"결과 : 6"`)


### 계산 진행
- [ ] 문자열 내의 숫자들은 구분자를 기준으로 구분하여 숫자를 추출한다.

- [ ] 추출하여 나온 숫자들을 모두 합한다.


### 구분자 규칙
- [ ] 쉼표(`,`)나 콜론(`:`)을 구분자로 하는 경우, 구분자를 기준으로 분리한다.

- [ ] 커스텀 구분자의 경우, 문자열 앞부분에 `"//"`와 `"\n"` 사이에 위치한 문자를 구분자로 사용한다.


### 도메인 규칙/검증
- [ ] 커스텀 구분자가 알맞은 형식인지 확인한다.

- [ ] 숫자가 양수인지 확인한다.


### 예외/엣지 케이스
- [ ] 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨다.

- [ ] 구분자로 추출된 문자가 숫자가 아닐 시 `NumberFormatException`을 발생시킨다.

- [ ] 구분자로 추출된 문자가 너무 큰 숫자일 경우 `NumberFormatException`을 발생시킨다.

- [ ] 숫자들을 모두 합한 값이 너무 클 때 `ArithmeticException`을 발생시킨다.
